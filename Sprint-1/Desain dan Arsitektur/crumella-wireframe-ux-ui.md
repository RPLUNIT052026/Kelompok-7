# Crumella – Wireframe UX/UI

Desain Figma: https://www.figma.com/design/DSpvdaXdBLJfJnEdVThJDZ

## Ringkasan

- 14 frame mobile berukuran 390×844 dalam satu halaman ("Wireframes")
- Layer bisa diedit (bukan gambar): teks, auto-layout, dan komponen sederhana
- Gaya low-fi abu-abu: kotak gambar bersilang X, tombol utama gelap, navigasi bawah konsisten
- Font: Poppins
- Isi teks dan tata letak tiap layar adalah interpretasi dari daftar layar; sesuaikan dengan dokumen sumber

## Daftar Frame

| Baris | Kode | Frame | Isi utama |
|-------|------|-------|-----------|
| 1 | A | Splash Screen | Logo, nama "Crumella", tagline |
| 1 | B | Onboarding slide 1–3 | Ilustrasi, judul, deskripsi, indikator halaman, tombol Next / Get Started, Skip |
| 2 | C | Log In / Sign Up | Tab Log In / Sign Up, input email dan password, tombol Log In, Continue with Google |
| 2 | D | Home | Sapaan "Hi, Sweetie <3", pencarian, banner promo, kategori, produk populer, navigasi bawah |
| 2 | E | Menu | Pencarian, kategori, daftar produk dengan tombol tambah, navigasi bawah |
| 2 | F | Detail Produk | Gambar produk, nama dan harga, deskripsi, ukuran, jumlah, tombol Add to Cart |
| 3 | G | Cart | Daftar item dengan pengatur jumlah, ringkasan biaya, tombol Checkout |
| 3 | H | Checkout | Alamat pengiriman, metode pembayaran, ringkasan pesanan, tombol Place Order |
| 3 | I | Profil | Avatar, nama dan email, menu (Edit Profil, Riwayat Pesanan, dll.), navigasi bawah |
| 3 | J | Edit Profil | Foto, input nama, email, telepon, alamat, tombol Save Changes |
| 4 | K | Konfirmasi Pesanan | Ikon centang, nomor pesanan, estimasi waktu, total, tombol Track Order / Back to Home |
| 4 | L | Riwayat Pesanan | Daftar pesanan dengan status dan tombol Reorder, navigasi bawah |

Baris 4 diberi judul "Usulan Halaman Tambahan (belum ada di Figma)".

## Alur Layar

```
Splash → Onboarding 1 → 2 → 3 → Log In / Sign Up → Home
Home ⇄ Menu → Detail Produk → Cart → Checkout → Konfirmasi Pesanan
Profil → Edit Profil
Profil → Riwayat Pesanan
```
